# Информационная система для управления подписками

## Описание проекта

Этот проект направлен на создание информационной системы для управления системой подписок на издания в почтовых отделениях города. Приложение разработано на базе технологий **ASP.NET MVC** и **Microsoft SQL Server**. Проект предоставляет решение для управления процессами распространения подписок, включая систему регистрации и авторизации пользователей, а также возможность просмотра записей таблиц.

Проект следует принципам **чистой архитектуры**, предложенной Робертом Мартином, обеспечивая модульную и независимую структуру системы. Компоненты архитектуры взаимодействуют друг с другом через интерфейсы, минимизируя связанность и упрощая поддержку, тестирование и расширение функциональности.

Основные компоненты архитектуры:
- **Domains** — содержит классы моделей и вспомогательные модели для работы с базой данных.
- **Repository** — посредник между приложением и базой данных, отвечает за хранение контекста и обеспечение целостности данных.
- **Service** — содержит бизнес-логику и правила обработки данных.
- **Web** — отвечает за веб-приложение, включая обработку запросов, визуализацию данных и взаимодействие с пользователями.

## Технологии

В проекте использованы следующие технологии:
- **ASP.NET MVC** — шаблон проектирования, разделяющий логику приложения на три компонента: Модель, Представление и Контроллер.
- **.NET Core** — кроссплатформенный фреймворк для создания высокопроизводительных приложений.
- **Microsoft SQL Server** — реляционная СУБД, обеспечивающая надёжное и безопасное хранение данных.
- **Entity Framework** — ORM для работы с базой данных, обеспечивающий высокий уровень абстракции.
